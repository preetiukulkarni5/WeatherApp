🌤️ Weather App

A lightweight weather app using HTML, CSS, and JavaScript that fetches real-time weather data from the OpenWeather API.
A simple and interactive weather application built using Vanilla JavaScript.

Features:

Search weather by city name
Displays temperature, wind speed, and weather description
Uses OpenWeather API for real-time data
Clean and responsive UI
